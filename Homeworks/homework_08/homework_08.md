# Задача 1: Сеть: 192.168.0.0 /24
1. 2^5 - 2 = 30 | 32 - 5 = 27 - Это новая маска.
2. 2^3 = 8 - Это общее количество подсетей, использовать можно будет 5, остальные резервные.
3. 2^5 - 2 = 30 - Это количество хостов в каждой подсети.

# Задача 2:Сеть: 192.168.50.0/24

2. 255.255.255.224 - Потому что мы заменяем первые три бита на единицы. 
3. 11100000 | 1^1 + 1^2 + 1^3 | 128 + 64 + 32 = 224
4. 32 - 27 = 5 | 2^5 - 2 = 30 - Это количество хостов в каждой подсети. | 256 - 224 = 32 - Нужный шаг.
